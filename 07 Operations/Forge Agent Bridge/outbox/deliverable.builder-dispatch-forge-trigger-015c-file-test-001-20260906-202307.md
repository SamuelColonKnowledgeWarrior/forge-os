## Recommendation

Adopt a mandatory "status truth" close-out gate on every Knowledge Warrior work package: no task may be marked complete until the deliverable's evidence path is verified to exist and its stated status word (proposed / created / configured / tested / deployed / active) matches an actual, checkable artifact — closing the gap between claimed and demonstrated progress.

**Why this matters:** the single most common execution-discipline failure is status drift — reporting a step as done when only the intent or a partial artifact exists. A hard verification gate before close-out removes ambiguity, keeps the audit trail honest, and prevents downstream agents/decisions from building on unconfirmed work.
