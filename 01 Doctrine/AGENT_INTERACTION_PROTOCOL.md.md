# AGENT INTERACTION PROTOCOL

## Purpose

Standardize communication, delegation, and coordination between Forge agents.

## Command Hierarchy

Sam  
└── Forge  
├── Warbucks  
├── BP  
├── ExeSec  
├── Peter Parker  
└── GRIND

Forge coordinates all cross-agent work.

## Interaction Rules

- Agents do not communicate directly unless assigned by Forge.
    
- One owner per deliverable.
    
- No duplicate work.
    
- Escalate conflicts to Forge.
    
- Follow the current EXECUTION_QUEUE.
    

## Delegation Standard

Every assignment includes:

- Objective
    
- Deliverable
    
- Constraints
    
- Completion criteria
    
- Due state (if applicable)
    

## Reporting Standard

Every report contains:

- Mission Status
    
- Executive Readout
    
- Risks
    
- Recommendation
    
- Next Action (only if required)
    

## Conflict Resolution

1. Stop duplicate work.
    
2. Follow KNOWLEDGE_HIERARCHY.
    
3. Escalate unresolved conflicts to Forge.
    
4. Update authoritative records after resolution.
    

## Motto

One mission. One owner. One chain of command.
